FUNDAMENTAL CONCEPT
TF-IDF
How TF-IDF works

TF-IDF = Term Frequency × Inverse Document Frequency.

TF-IDF stands for Term Frequency–Inverse Document Frequency. Start from Bag of Words, then reweight each word so common words shrink and distinctive words stand out.

TF = Term Frequency
How often the term appears in this email

Term = a word (or short phrase). If "deadline" appears twice in one short email, its Term Frequency is high for that email.

IDF = Inverse Document Frequency
How rare the term is across many documents

Document = one email. Inverse = rare terms score higher. "the"/"sale" in many emails → low IDF. "deadline" in few emails → high IDF.

TF-IDF(word) = Term Frequency × Inverse Document Frequency

FUNDAMENTAL CONCEPT
LOGISTIC REGRESSION
How the classifier learns

LogReg turns weights into an important / not flag.

Each TF-IDF word feature gets a learned coefficient. Positive push toward important; negative push toward not important.

Step-by-step
1
Receive TF-IDF vectorExample features: deadline, project, sale, …
2
Multiply each feature × learned weightTraining adjusts those weights using labeled emails.
3
Sum → score → probabilityA sigmoid maps the score to a value between 0 and 1.
4
Threshold → final labele.g. if probability ≥ 0.5 → important, else not_important.
score = w₁x₁ + w₂x₂ + … + bias
P(important) = sigmoid(score)

Train vs predict: training learns the weights from labeled data. Prediction applies the fixed weights to a new email. We can later inspect top words as model evidence.
