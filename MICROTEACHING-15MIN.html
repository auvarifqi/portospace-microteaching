FUNDAMENTAL CONCEPT
TEACH ONE CONCEPT
How does AI "read" text?

Computers need to turn words → numbers.

We start with Bag of Words: count how many times each word appears.

Example email
"project deadline"

Our chosen vocabulary:

deadlineprojectsale
Vector in order: [deadline, project, sale]
1
deadline
1
project
0
sale

Now the text is numeric data.

Next level: TF-IDF helps weight more informative words/phrases; Logistic Regression learns how those numbers relate to the label. Later we can try denser "meaning vectors" from a pretrained model.
